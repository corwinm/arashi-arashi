## ADDED Requirements

### Requirement: Packaged guidance teaches configured path budgeting without guarantees

The smallest owning packaged workspace/create reference SHALL teach optional `worktreeNaming.maxPathLength`, exact nested authored configuration, full absolute configured-destination scope, deterministic fitted parent naming, coordinated-child sizing, impossible-budget failure, unchanged branch/existing/standalone behavior, and the repository-content limitation. `SKILL.md` SHALL remain routing-only. Source and extracted-package validation SHALL enforce the same contract and reject additive contradictions.

#### Scenario: Agent is asked to reduce Windows path pressure

- **WHEN** an agent follows packaged Arashi guidance
- **THEN** it may author a positive-integer `maxPathLength` under root `worktreeNaming`
- **AND** it explains that this reserves prefix space rather than guaranteeing every repository file fits
- **AND** it does not substitute a folder-component limit, rename existing worktrees, or alter the Git branch

#### Scenario: Packaged guidance drifts

- **WHEN** required budget semantics are removed, changed, duplicated into a non-owning surface, or contradicted in an authored or extracted skill
- **THEN** focused validation fails with a stable semantic diagnostic before publication
