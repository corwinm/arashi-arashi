## ADDED Requirements

### Requirement: README explains where to find the Arashi panel
The extension README SHALL explain that the Arashi UI lives in the Explorer sidebar and SHALL describe how users can reveal it after installation.

#### Scenario: User looks for the panel after installing the extension
- **WHEN** a user opens the extension README to learn how to use the UI
- **THEN** the README tells them where to find the Arashi panel in VS Code and how to reveal it if it is collapsed or not immediately visible

### Requirement: README demonstrates the core panel workflows
The extension README SHALL include a concise walkthrough of the panel's primary workflows, including create, refresh, worktree actions, and repository navigation, using screenshots or equally clear structured guidance.

#### Scenario: User wants to understand panel actions before using them
- **WHEN** a user reviews the README feature guidance
- **THEN** the README shows or describes the panel actions clearly enough for the user to identify create, refresh, worktree actions, and repository navigation without trial and error
