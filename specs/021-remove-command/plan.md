## Summary

The Remove Command enables developers to clean up completed feature branches by removing worktrees and deleting branches across the main repository and all sub-repositories with a single command. The implementation follows the established command pattern used by existing commands (add, create, init, list, status) and integrates with the existing git utility library, configuration system, and rollback mechanism.

## Technical Context

**Language/Version**: TypeScript (latest stable) with Bun (latest stable version for bundling and runtime)  
**Primary Dependencies**: commander (CLI framework), chalk (colored output), ora (spinners), @inquirer/prompts (user prompts), Bun runtime (built-in APIs - spawn, file system, path)  
**Storage**: File system (`.arashi/config.json` for workspace configuration, git metadata from `.git/worktrees/`)  
**Testing**: Bun test runner (built-in), integration tests  
**Target Platform**: macOS ARM64, Linux x64, Windows x64 (cross-platform CLI)  
**Project Type**: Single project (CLI tool)  
**Performance Goals**: Complete single branch removal in under 30 seconds, multi-branch removal with interactive selection in under 60 seconds  
**Constraints**: Must use git worktree remove for safe deletion, must handle partial failures gracefully, must maintain workspace consistency  
**Scale/Scope**: Support 5-10 sub-repositories per workspace, handle 10-50 worktrees per workspace
